# Amazon Product Data Scraper using Selenium

A Python-based web scraping project that uses Selenium WebDriver to collect
product listing HTML data from Amazon India search result pages.

## Features

- Automates Chrome using Selenium WebDriver
- Searches Amazon India for a specified product
- Scrapes product listing elements from multiple pages
- Saves the scraped HTML data as individual files
- Automatically creates the output directory

## Technologies Used

- Python
- Selenium
- Chrome WebDriver
